# 易县三中表白墙 · 0元互联网部署版

推荐架构：Render 免费 Flask Web Service + Supabase Free PostgreSQL。

Render 官方支持 Python/Flask Web Service，部署时可使用 `pip install -r requirements.txt` 和 `gunicorn app:app`。免费 Web Service 会在一段时间没有请求后休眠；免费实例不提供持久化本地文件系统，所以本项目把投稿数据放在独立 PostgreSQL 数据库中。

## 你需要准备

1. GitHub 账号
2. Render 账号
3. Supabase 账号

如果某个平台对未成年人账号有限制，请让家长/监护人按照平台规则协助完成注册，不要绕过年龄验证。

## 第一步：Supabase

创建一个 Free 项目。

在 Supabase 的 SQL Editor 执行：

```sql
create table if not exists posts (
  id bigint generated by default as identity primary key,
  nickname text not null,
  grade text default '',
  content text not null,
  anonymous boolean default true,
  status text default 'pending',
  likes integer default 0,
  created_at timestamptz default now()
);

create table if not exists comments (
  id bigint generated by default as identity primary key,
  post_id bigint not null references posts(id) on delete cascade,
  nickname text not null,
  content text not null,
  status text default 'approved',
  created_at timestamptz default now()
);

create table if not exists reports (
  id bigint generated by default as identity primary key,
  post_id bigint not null references posts(id) on delete cascade,
  reason text default '',
  created_at timestamptz default now()
);
```

然后打开 Supabase 的 Connect，找到 PostgreSQL 的 **Session pooler** 连接字符串。

把它作为 Render 的 `DATABASE_URL`。

## 第二步：GitHub

把整个项目文件上传到一个 GitHub 仓库。

根目录必须有：

- app.py
- requirements.txt
- render.yaml
- templates/
- static/

## 第三步：Render

Render → New → Web Service → 连接你的 GitHub 仓库。

如果手动填写：

Build Command:
```text
pip install -r requirements.txt
```

Start Command:
```text
gunicorn app:app
```

选择 Free。

Environment Variables 添加：

```text
DATABASE_URL=你的Supabase Session pooler连接字符串
SECRET_KEY=随机长字符串
ADMIN_USER=你自己的管理员账号
ADMIN_PASSWORD=你自己的强密码
```

部署成功后 Render 会给你一个 `onrender.com` 网址，手机直接打开即可。

## 重要

Render 官方说明免费 Web Service 会休眠，本地文件系统不能作为免费服务的长期持久化存储；因此不要把投稿数据重新改回 SQLite。

Supabase Free 当前提供免费 Postgres，但免费项目存在配额和暂停等限制；不要把它当作重要数据的唯一备份。

正式给大量学生使用前，建议增加更严格的审核、举报、限流、日志和备份。
